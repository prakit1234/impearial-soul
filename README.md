# Impearial Soul - Rule with grace. Live with soul.

An elegant e-commerce platform offering a unique shopping experience with customizable themes.

## Features
- Four distinct themes: Aesthetic, Tree, Cloud, and Moon vibes
- Firebase phone authentication
- Responsive design
- Theme customization
- Secure checkout process
- Optional user accounts
- Direct product browsing

## Use
-  Visit [Cloudflare](https://impearial-soul.pages.dev)
    or [Vercel](https://impearial-soul.vercel.app)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Node.js modules

## Theme Options
- Aesthetic Vibe: Minimalist and artistic
- Tree Vibe: Nature-inspired and earthy
- Cloud Vibe: Light and airy
- Moon Vibe: Dark and mysterious
